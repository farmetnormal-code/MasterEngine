Master Engine API

Полный справочник по всем функциям движка (v7.8.0 Data-Oriented Behemoth).

Система и Утилиты

master.screen_w, master.screen_h
Глобальные переменные. Содержат текущую ширину и высоту экрана устройства в пикселях.
master.getScreenCenter() -> x, y
Возвращает координаты центра экрана.
master.getTime() -> float
Время в секундах, прошедшее с момента старта движка.
master.getFPS() -> float
Возвращает текущее количество кадров в секунду (FPS).
master.setTimeScale(scale)
Масштаб времени. По умолчанию 1.0. Установите 0.5 для замедления времени (слоу-мо) в 2 раза.
master.optimizeGC() / master.collectGarbage()
Настройка сборщика мусора Lua. Рекомендуется вызывать optimizeGC() один раз при старте для предотвращения фризов.
master.getLuaMemory() -> float
Возвращает объем оперативной памяти (в Мегабайтах), используемый скриптами Lua.
master.getCPUs(), master.getRAM(), master.getBattery(), master.getPlatform()
Информация о железе: количество ядер, объем ОЗУ устройства, заряд батареи (в %) и платформа.
master.quit()
Мгновенное закрытие игры/движка.
master.openURL(url) / master.showMessage(title, text)
Открывает системный браузер по ссылке или показывает нативное диалоговое окно Android.

Ввод (Тач, Геймпад, Текст)

master.getTouch() -> x, y, is_pressed
Возвращает координаты первого (главного) касания и флаг, нажат ли экран.
master.getTouches() -> table
Поддержка мультитача. Возвращает массив таблиц (пальцев). Пример: for i, t in ipairs(touches) do print(t.id, t.x, t.y) end
master.getGamepadAxis(id) -> float / master.getGamepadButton(id) -> bool
Чтение состояния подключенного Bluetooth/USB геймпада (от -1.0 до 1.0 для стиков).
master.gamepadRumble(low_freq, high_freq, ms)
Вибрация геймпада (значения от 0.0 до 1.0 на указанное количество миллисекунд).
master.startTextInput(), master.stopTextInput(), master.getTextInput(), master.clearTextInput()
Управление системной клавиатурой. getTextInput() возвращает строку, которую напечатал пользователь.
master.getClipboardText() -> string / master.setClipboardText(text)
Чтение и запись системного буфера обмена Android.

Базовый Рендер и Фигуры

Рисование стандартных геометрических фигур. Поддерживает альфа-канал и автоматическое применение камеры.

master.clear(r, g, b)
Очистка экрана заданным цветом. Обязательно вызывать в начале master.draw().
master.drawRect(x, y, w, h, r, g, b) / master.drawRectAlpha(..., a)
Отрисовка закрашенного прямоугольника (без прозрачности и с прозрачностью 0-255).
master.drawLine(x1, y1, x2, y2, r, g, b) / master.drawThickLine(..., thick, r, g, b, a)
Отрисовка линии толщиной 1 пиксель или линии с заданной толщиной и прозрачностью.
master.drawCircle(x, y, radius, r, g, b)
Рисует окружность.
master.drawTriangle(x1,y1, x2,y2, x3,y3, r,g,b) / master.drawBezier(x1,y1, x2,y2, x3,y3, r,g,b)
Отрисовка контура треугольника и плавной кривой Безье по 3 точкам.
master.drawPolygon(points_table, r, g, b)
Отрисовка многоугольника. Принимает массив точек: {{x=0,y=0}, {x=50,y=10}, ...}
master.setPixel(x, y, r, g, b)
Закрашивает один конкретный пиксель на экране.

Текстуры, Спрайты и Текст

master.loadImage(filename) -> pointer
Загружает изображение (PNG, JPG) из вашего .zip архива. Кэшируется в NDK.
master.drawSprite(tex, x, y, w, h)
Обычная отрисовка текстуры.
master.drawSpriteEx(tex, x, y, w, h, angle, flip_x, flip_y)
Отрисовка с поворотом (в градусах) и возможностью отзеркалить по осям.
master.drawSpritePart(tex, sx, sy, sw, sh, dx, dy, dw, dh)
Вырезает кусок из текстуры (Source X/Y/W/H) и рисует его на экране (Dest X/Y/W/H). Идеально для анимаций.
master.setTextureAlpha(tex, a) / master.setSpriteTint(tex, r, g, b)
Устанавливает глобальную прозрачность (0-255) или цветовое тонирование (Tint) для текстуры.
master.setBlendMode(tex, mode)
Режим смешивания. Доступны: "blend" (обычный), "add" (добавление/свет), "mod" (умножение/тени).
master.loadFont(filename, size) -> pointer
Загружает .ttf шрифт из архива.
master.drawSystemText(text, x, y, r, g, b, size) / master.drawText(font_ptr, text, x, y, r, g, b)
Рисует текст стандартным шрифтом движка (system) или вашим загруженным шрифтом.
master.getTextWidth(text, size) -> float
Вычисляет ширину строки в пикселях. Полезно для выравнивания текста по центру.

Hypercar & Data-Oriented Batching

Система аппаратного рендера геометрии (до 100,000+ объектов). Избегайте ООП при отрисовке, используйте плоские массивы.

master.createSpriteBatch(texture_ptr) -> BatchObject
Создает объект батчера для указанной текстуры (или канваса).
master.setBatch(BatchObject)
Устанавливает текущий батчер в ядре C++. Открывает Bypass канал.
master.addBatchFast(x, y, w, h, r, g, b, a)
Сверхскоростная (плоская) функция добавления прямоугольника/спрайта в буфер видеокарты.
master.addBatchArraysFlat(xs_table, ys_table, w, h, r, g, b, a, count)
(The Array Bridge). Ультимативный Data-Oriented метод. Принимает целиком две таблицы с координатами и отрисовывает десятки тысяч объектов за один вызов к C++. Избавляет от узкого горлышка (циклов `for` в Lua при рендере).
-- Пример Data-Oriented рендера 40,000 частиц:
local xs = {10, 50, 100, ...} -- 40k элементов
local ys = {20, 60, 110, ...}

batch:clear()
master.setBatch(batch)
master.addBatchArraysFlat(xs, ys, 8, 8, 255, 0, 0, 255, 40000)
batch:draw()

Камера, Culling и Эффекты

master.setCamera(x, y, zoom) / master.resetCamera()
Сдвигает и масштабирует весь рендер. Обычно передаются координаты игрока. resetCamera() сбрасывает настройки (нужно вызывать перед отрисовкой UI).
master.isOnScreen(x, y, w, h) -> bool
Frustum Culling: Быстрая проверка на стороне C++, попадает ли объект в текущий объектив камеры (с учетом зума и тряски экрана). Позволяет пропускать тяжелую математику и рендер для невидимых объектов.
master.screenShake(intensity, duration)
Аппаратная тряска экрана. `intensity` — сила дрожания в пикселях, `duration` — время в секундах.
master.createCanvas(w, h) -> texture_ptr
Создает пустую текстуру-канвас в видеопамяти. На ней можно рисовать и использовать её как обычный спрайт.
master.setCanvas(texture_ptr) / master.resetCanvas()
Перенаправляет весь рендер движка не на экран, а внутрь текстуры-канваса. Сброс возвращает рендер на экран.
master.takeScreenshot(filename)
Делает скриншот игры и сохраняет его во внутреннюю папку приложения с указанным именем (напр. "screen.png").
master.emitParticlePro(x, y, vx, vy, life, start_size, end_size, sr, sg, sb, sa, er, eg, eb, ea, spin, grav, fric)
Генерация продвинутой частицы. Автоматически обрабатывается в C++. Обязательно вызывайте master.updateAndDrawParticles() каждый кадр!

Звук и Музыка (SDL Mixer)

master.loadSound(filename) -> ptr / master.playSound(ptr)
Загружает звуковой эффект (.wav, .ogg) и проигрывает его. Звуки могут накладываться друг на друга.
master.loadMusic(filename) -> ptr / master.playMusic(ptr, loops)
Загружает фоновую музыку (.mp3, .ogg). loops = -1 для бесконечного повтора.
master.pauseMusic() / master.resumeMusic() / master.stopMusic()
Управление потоком фоновой музыки.
master.isMusicPlaying() -> bool / master.setVolume(0-128)
Проверка проигрывания и глобальная установка громкости.

Продвинутая Математика

Все функции вынесены в C++ для мгновенного выполнения.

master.distance(x1,y1, x2,y2) / master.getAngleDeg(x1,y1, x2,y2)
Дистанция между точками и вычисление угла в градусах.
master.moveAtAngle(x, y, angle_deg, distance) -> new_x, new_y
Вычисляет новые координаты при движении в определенном направлении.
master.lerp(a, b, t) / master.lerpAngle(a, b, t) / master.colorLerp(r1,g1,b1, r2,g2,b2, t)
Линейная интерполяция значений, углов (с правильным переходом через 360) и цветов.
master.randomFloat(min, max) / master.randomInt(min, max)
Сверхбыстрые генераторы случайных чисел, работающие на уровне ядра движка (быстрее, чем math.random).
master.vecNormalize(x, y) -> nx, ny / master.vecLength(x, y) / master.vecDot(x1,y1,x2,y2)
Векторная математика: нормализация, длина вектора и скалярное произведение.
master.rectIntersect(x1,y1,w1,h1, x2,y2,w2,h2) / master.circleIntersect(x1,y1,r1, x2,y2,r2)
Проверка коллизий AABB (прямоугольники) и окружностей. Возвращает true/false.
master.noise(x, y) / master.perlin2D(x, y)
Генерация шума (Perlin Noise) для создания процедурных ландшафтов. Возвращает значения от -1.0 до 1.0.
master.colorHSV(h, s, v) -> r, g, b
Конвертация цветовой модели HSV (Hue, Saturation, Value) в RGB. Идеально для переливающихся цветов.

Сеть (ENet Мультиплеер)

master.netConnect(ip_string, port) -> bool
Подключается к ENet серверу (UDP протокол). Возвращает true в случае успеха.
master.netSend(data_string)
Отправляет строку данных на сервер (используйте master.jsonStringify() для таблиц). Отправка надежная (Reliable).
master.netReceive() -> string
Принимает входящие пакеты. Возвращает строку или пустую строку "", если новых данных нет. Должна вызываться каждый кадр в цикле.

Базы данных (SQLite)

Встроенная локальная база данных на устройстве.

master.dbOpen(filename) / master.dbClose()
Открывает файл БД (например, "save.db"). Если файла нет, он будет создан.
master.dbExecute(sql_query_string)
Выполняет SQL-запрос, который не возвращает данные (CREATE TABLE, INSERT, UPDATE).
master.dbQuery(sql_query_string) -> table
Выполняет SELECT-запрос и возвращает массив таблиц (строк) с результатами из БД.

Криптография, JSON и Сохранения

master.saveData(key, string_val) / master.loadData(key) -> string
Быстрое сохранение строк в защищенную папку приложения (SharedPreferences аналог).
master.jsonParse(json_string) -> table / master.jsonStringify(lua_table) -> string
Быстрая конвертация таблиц Lua в JSON и обратно через библиотеку cJSON.
master.base64Encode(string) -> string / master.base64Decode(string) -> string
Кодирование и декодирование любых строк в формат Base64. Полезно для упаковки бинарных данных или обфускации сохранений.
master.hashString(text) -> hex_string
Возвращает SHA-256 хэш строки.
master.signData(data, secret_key) -> hex_string
Подписывает данные секретным ключом. Используется для защиты сохранений от взлома (анти-чит).

Core Framework (ECS, Grid, Сцены)

master.ecs.create({components...}) / master.ecs.update(dt) / master.ecs.draw()
Встроенная Entity-Component-System. У каждой сущности могут быть функции update(self, dt) и draw(self). Установка entity.dead = true удалит её.
master.grid.size / master.grid.insert(id, x, y) / master.grid.getNearby(x, y) / master.grid.clear()
Spatial Hash Grid (Пространственное хеширование): Делит игровой мир на квадраты размером size. Позволяет мгновенно получать список соседей (например, врагов) вокруг конкретной точки, избегая проверки расстояния до всех объектов на карте (O(n) -> O(1)). Вызывайте clear() каждый кадр перед новым заполнением.
master.timers.setTimeout(sec, func) / master.timers.setInterval(sec, func)
Асинхронные таймеры. Требуют вызова master.timers.update(dt) в главном цикле.
master.events.on(name, func) / master.events.emit(name, args...)
Глобальная шина событий для связи разных частей кода без сильной связности.
master.path.initGrid(w, h) / master.path.setObstacle(x, y, is_obs) / master.path.find(sx, sy, ex, ey)
Встроенный алгоритм поиска пути A* (A-Star) на сетке. Возвращает массив узлов.
master.anim.new(frames_table, speed) / master.anim.update(anim, dt) / master.anim.getFrame(anim)
Легковесная стейт-машина для переключения кадров (Quad'ов) спрайта по таймеру.

Индустриальная физика (Box2D)

Ядро включает полную реализацию физики Box2D. Работает через ООП-биндинги Sol2.

b2World(b2Vec2_gravity)
Создание физического мира. Методы: Step(dt, v_iter, p_iter), CreateBody(b2BodyDef), DestroyBody(body), RayCast(x1,y1, x2,y2, callback).
b2BodyDef / b2Body
Определение тела и само тело. Типы (type): b2_staticBody, b2_dynamicBody, b2_kinematicBody. Методы тела: GetPosition(), CreateFixture(fixtureDef), ApplyLinearImpulse(...).
b2PolygonShape / b2CircleShape
Формы коллайдеров. У полигона есть метод SetAsBox(half_w, half_h). У круга: m_radius.
b2FixtureDef
Определяет физические свойства: shape, density (плотность), restitution (отскок), friction (трение), isSensor.

Секретные флаги (Internal)

!master.hidedErdisplay
Режим Бога (Игнорирование крашей): Если написать эту точную строку в любом месте файла main.lua в виде комментария (например: -- !master.hidedErdisplay), C++ парсер движка отключит защиту "Синего Экрана Смерти". При возникновении критических ошибок Lua, движок не покажет экран с логом ошибки, а попытается проглотить её и продолжить работу (может привести к нестабильности).
