Масштабируемость и Мощь

Master Engine использует технологию Bypass Protocol для обеспечения прямой связи скриптов Lua с NDK. Архитектура движка исключает узкие места при выделении памяти (Zero Allocation), позволяя рендерить масштабные сцены.

  • 56,000+ спрайтов на экране без падения FPS (аппаратный Vertex Batching).
  • Индустриальная физика: интеграция Box2D для реалистичных столкновений и гравитации.
  • Оптимизация памяти: кэширование текстур, аудио и вершинных буферов на уровне C++.
  • Навигация и Мультиплеер: встроенные модули алгоритма A* и сетевой библиотеки ENet.

1. Основы (Core API)

Главная функция движка, которая вызывается каждый кадр — master.draw(). В ней пишется базовая логика игры.

-- Получить Delta Time (время между кадрами для плавной логики)
local dt = master.dt

-- Очистка экрана (R, G, B)
master.clear(15, 15, 20)

-- Базовая отрисовка без аппаратного ускорения
master.drawRect(x, y, w, h, r, g, b)
master.drawCircle(x, y, radius, r, g, b)
master.drawSystemText("Текст", x, y, r, g, b, size)
master.drawFPS(x, y)

2. Сверхбыстрый Рендер (SpriteBatch)

Для отрисовки тысяч объектов используйте плоские функции батчера в обход накладных расходов ООП.

local batch = nil

-- Инициализация (делать 1 раз!)
local tex = master.createCanvas(10, 10)
batch = master.createSpriteBatch(tex)

function master.draw()
    batch:clear()
    master.setBatch(batch) -- Передаем указатель в C++
    
    -- Отрисовка 10,000 объектов мгновенно
    for i=1, 10000 do
        -- (x, y, w, h, r, g, b, alpha)
        master.addBatchFast(x, y, 16, 16, 255, 0, 0, 255)
    end
    
    batch:draw()
end

4. Фреймворк: ECS и Сцены

Движок имеет встроенный архитектурный фреймворк для управления жизненным циклом сущностей.

-- Создание сущности
master.ecs.create({
    type = "player",
    x = 100, y = 100,
    update = function(self, dt)
        self.x = self.x + 100 * dt
    end
})

-- В master.draw() необходимо вызвать обновление:
master.ecs.update(master.dt)

-- Сцены
master.scenes.switch(menu_scene)

5. Система Частиц Pro

Аппаратные частицы с гравитацией, трением, вращением и плавным переходом цвета (Color Fade).

-- (x, y, vx, vy, life, start_size, end_size, start_R, start_G, start_B, start_A, end_R, end_G, end_B, end_A, spin, gravity, friction)

master.emitParticlePro(cx, cy, vx, vy, 1.5, 
    15, 0,           -- Размер (уменьшается)
    255, 50, 0, 255, -- Стартовый цвет (Красный)
    100, 0, 0, 0,    -- Конечный цвет (Темный прозрачный)
    180, 0.5, 1.5)   -- Вращение, гравитация, трение

-- Не забудьте вызвать отрисовку частиц в master.draw()
master.updateAndDrawParticles()
